# CoilPro logo

"Grundriss-C": a petrol tile with a white "C" drawn as floor-plan walls and one amber room. All SVGs are
pure paths (text converted to outlines), so they render without fonts.

| File | Use |
|---|---|
| `coilpro-logo.svg` | Mark + two-line wordmark on light backgrounds (174×72) |
| `coilpro-logo-inverse.svg` | Same for dark backgrounds |
| `coilpro-logo-line.svg` / `-line-inverse.svg` | Single line for headers (174×44) — used by the docs site |
| `coilpro-mark.svg` | Mark only (64×64) |
| `coilpro-favicon.svg` | Favicon, from 32 px |
| `coilpro-app-icon-1024.png` | Large raster icon (e.g. GitHub social preview) |
| `../icon.png` | 512 px app icon, used as the NuGet package icon |

Colours: petrol `#14505C`, deep petrol `#0D3A44`, light petrol `#3C7885`, mist `#B8D3D9`,
amber `#E0A458` (only the square in the mark), white.

Rules: keep a clear space of at least the stroke width of the C around the logo; mark at least 16 px,
wordmark at least 120 px wide; never recolour the amber square; no gradients, shadows or rotation.
